# Laboratório de Banco de Dados

Clique no botão abaixo para abrir seu ambiente completo de laboratório no navegador:

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/SEU_USUARIO/lab-banco-de-dados)

Como Utilizar:
1 - Clique no link acima (Create codespace), abrindo em uma nova aba, preferencialmente.
2 - O carregamento demora um pouco (entre 5 e 15 minutos), após o carregamento, o VS Code abre no navegador.
3 - No menu lateral esquerdo, haverá um ícone de banco de dados (SQLTools). A conexão "PostgreSQL da Turma" já aparecerá listada.

Você pode criar seus póprios arquivos dentro do VScode e executá-los diretamente no banco em nuvem clicando em "Run on active connection (ou Ctrl+E)", visualizando o grid com os resultados das consultas na lateral.
